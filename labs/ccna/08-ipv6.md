# CCNA 08: IPv6, endereçamento e rotas estáticas

**Objetivo:** configurar endereços globais e link-local, SLAAC nos hosts e rotas estáticas IPv6 (incluindo rota padrão e flutuante).

## Topologia

Mesma do [lab 04](04-rotas-estaticas.md), em **dual stack** (mantenha o IPv4).

| Link | Prefixo | R-A | R-B |
|------|---------|-----|-----|
| R1–R3 | 2001:db8:13::/64 | R1 ::1 | R3 ::3 |
| R1–R2 | 2001:db8:12::/64 | R1 ::1 | R2 ::2 |
| R2–R3 | 2001:db8:23::/64 | R2 ::2 | R3 ::3 |
| LAN R1 | 2001:db8:1::/64 | R1 ::1 | PC1 via SLAAC |
| LAN R3 | 2001:db8:3::/64 | R3 ::1 | PC2 via SLAAC |
| R2 Lo0 | 2001:db8:ffff::2/128 | | |

Link-local fixo em todas as interfaces: `fe80::1` no R1, `fe80::2` no R2, `fe80::3` no R3.

## Tarefas

1. Ative `ipv6 unicast-routing` nos três roteadores.
2. Endereçe as interfaces com os prefixos da tabela e os link-local fixos.
3. Os PCs pegam endereço por **SLAAC** (`ip auto` no VPCS).
4. R1 → LAN do R3 pelo link direto, usando como próximo salto o **link-local** do R3 (exige informar a interface de saída).
5. Rota flutuante via R2 com distância 10.
6. R2 com rotas para as duas LANs.
7. R1 e R3 com **rota padrão IPv6** (`::/0`) apontando para o R2.
8. Identifique no `show ipv6 interface` os grupos multicast (`ff02::1`, `ff02::2`, solicited-node).

## Verificação

```
show ipv6 interface brief
show ipv6 interface Ethernet0/2
show ipv6 route static
show ipv6 neighbors
PC1> show ipv6
PC1> ping 2001:db8:3::<endereço-do-PC2>
```

- O endereço SLAAC do PC tem os 64 bits finais derivados do MAC (EUI-64) ou aleatórios.
- `show ipv6 route` mostra a rota via `FE80::3` com a interface `Ethernet0/0`.

<details>
<summary>Configuração de referência</summary>

**R1**

```
ipv6 unicast-routing
interface Ethernet0/0
 ipv6 address fe80::1 link-local
 ipv6 address 2001:db8:13::1/64
interface Ethernet0/1
 ipv6 address fe80::1 link-local
 ipv6 address 2001:db8:12::1/64
interface Ethernet0/2
 ipv6 address fe80::1 link-local
 ipv6 address 2001:db8:1::1/64
!
ipv6 route 2001:db8:3::/64 Ethernet0/0 fe80::3
ipv6 route 2001:db8:3::/64 2001:db8:12::2 10
ipv6 route ::/0 2001:db8:12::2
```

**R2**

```
ipv6 unicast-routing
interface Loopback0
 ipv6 address 2001:db8:ffff::2/128
interface Ethernet0/0
 ipv6 address fe80::2 link-local
 ipv6 address 2001:db8:12::2/64
interface Ethernet0/1
 ipv6 address fe80::2 link-local
 ipv6 address 2001:db8:23::2/64
!
ipv6 route 2001:db8:1::/64 2001:db8:12::1
ipv6 route 2001:db8:3::/64 2001:db8:23::3
```

**R3**

```
ipv6 unicast-routing
interface Ethernet0/0
 ipv6 address fe80::3 link-local
 ipv6 address 2001:db8:13::3/64
interface Ethernet0/1
 ipv6 address fe80::3 link-local
 ipv6 address 2001:db8:23::3/64
interface Ethernet0/2
 ipv6 address fe80::3 link-local
 ipv6 address 2001:db8:3::1/64
!
ipv6 route 2001:db8:1::/64 Ethernet0/0 fe80::1
ipv6 route 2001:db8:1::/64 2001:db8:23::2 10
ipv6 route ::/0 2001:db8:23::2
```

**VPCS**

```
PC1> ip auto
PC2> ip auto
```
